1) database.sql را در Supabase > SQL Editor اجرا کن (اگر قبلا همین جدول‌ها را ساخته‌ای، لازم نیست).
2) در Authentication > Users یک کاربر مدیر بساز.
3) index.html همین حالا با Project URL و Publishable Key پروژه شما تنظیم شده است.
4) سه فایل را روی GitHub Pages/Vercel/Netlify منتشر کن.
5) آدرس سایت را در Safari باز کن و Add to Home Screen بزن.
هرگز Secret/Service Role Key را داخل HTML قرار نده.
